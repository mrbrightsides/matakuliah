# Materi Mata Kuliah

Repository ini berisi kumpulan materi perkuliahan yang dapat digunakan mahasiswa sebagai bahan belajar mandiri dan referensi selama perkuliahan.

## 📚 Daftar Mata Kuliah

Materi disusun berdasarkan mata kuliah dan pertemuan.

### 1. Komputasi Numerik
Materi pembelajaran Komputasi Numerik.

### 2. Metode Numerik
Materi pembelajaran Metode Numerik.

### 3. Praktikum Algoritma
Materi praktikum dan latihan pemrograman.

## 📖 Cara Mengakses Materi

1. Pilih file sesuai mata kuliah.
2. Pilih pertemuan yang ingin dipelajari.
3. Klik file `.md` untuk membaca materi langsung di GitHub.
4. Untuk mengunduh, buka file kemudian pilih opsi **Download raw file**.

## 📝 Catatan

- Materi disusun secara bertahap berdasarkan pertemuan.
- Repository dapat diperbarui sewaktu-waktu.
- Mahasiswa disarankan memeriksa repository secara berkala untuk mendapatkan materi terbaru.
